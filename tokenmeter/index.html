How cost is calculated

Every model reply reports how many tokens of each type it used. Tokenmeter multiplies each type by that model's list price and adds them up:

cost = cached reads × read price + uncached input × input price + cache writes × write price + output × output price, all per million tokens

The types are priced very differently, so the token total alone does not predict cost. On Claude a cached read is about 2% of a fresh token, and output is 2 to 5 times a fresh token. Claude Code writes its cache with the 1-hour rate. OpenAI models do not charge for cache writes, and bill higher rates for any turn with more than 272K input tokens; Tokenmeter applies that per turn.
